# School Registration System

A web-based student registration system built with Flask, MySQL, JavaScript, HTML, and CSS.

## Features

- Student registration form
- Frontend validation using JavaScript
- Backend validation using Flask
- MySQL database integration
- School profile page
- Teacher information
- School gallery
- Responsive design

## Technologies Used

- Python (Flask)
- MySQL
- HTML5
- CSS3
- JavaScript

## Installation

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
